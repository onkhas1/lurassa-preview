# Люрасса — прототип сайта

Статический прототип сайта ресторана «Люрасса» для просмотра и обсуждения. Формы заказа и бронирования пока демонстрационные; доставка обозначена как будущая функция.

Опубликованная версия: https://onkhas1.github.io/lurassa-preview/

Исходная сборка проекта хранится отдельно в рабочем архиве.
